# 毕设答辩演示视频录制脚本

## 录制规格

| 项目 | 说明 |
|------|------|
| 总时长 | 约 3 分 50 秒 |
| 形式 | 屏幕录制 + 后期字幕/旁白 |
| 分辨率 | 1920×1080 |
| 录制工具 | OBS Studio 或系统自带录屏 |
| 录制方式 | 分段录制，后期剪辑拼接 |
| 快进段落 | 场景 2（基础数据）、场景 5（算法计算）可用 2 倍速 |

## 账号规划

| 场景 | 账号 | 角色 | 用途 |
|------|------|------|------|
| 场景 1 | admin / org_admin / operator / viewer | 四角色 | 侧边栏权限对比 |
| 场景 2 | org_admin | 组织管理员 | Excel 导入导出、板材图片 |
| 场景 3 | operator | 操作员 | 3D 柜体设计 |
| 场景 4 | operator | 操作员 | 增补订单 + 生成排版草稿 |
| 场景 5 | operator | 操作员 | 排版工作台 |
| 场景 6 Web | operator | 操作员 | 分配生产、看板 |
| 场景 6 小程序 | viewer | 生产员 | 接单、执行任务 |

---

## 场景 1：角色权限对比（0:00-0:40，40s）

> 分段录制，每段直接在已登录账号的页面展示侧边栏，后期剪辑拼接。

| 时间 | 操作 | 字幕/旁白 |
|------|------|-----------|
| 0:00-0:05 | 登录页画面，叠加文字说明四角色体系 | 系统采用四角色权限体系：系统管理员、组织管理员、操作员、生产员 |
| 0:05-0:15 | 已登录 admin，在个人设置页，鼠标缓慢扫过侧边栏：系统概览、组织管理、账号管理 | 系统管理员负责组织和账号的全局管理，不参与具体业务操作 |
| 0:15-0:25 | 已登录 org_admin，扫过侧边栏：工作台、生产看板、客户管理、板材管理、成员管理、审计日志 | 组织管理员拥有业务管理全权限，包括成员管理和审计日志 |
| 0:25-0:35 | 已登录 operator，扫过侧边栏：生产看板、客户管理、板材管理、订单录入、排版工作台 | 操作员负责核心业务——订单录入和排样计算，权限更聚焦 |
| 0:35-0:40 | 画面切换到微信小程序，已登录 viewer，展示「我的任务」列表 | 生产员通过小程序接收和执行生产任务 |

---

## 场景 2：数据管理特性展示（0:40-1:15，35s）

> 录制角色：org_admin。场景 2 部分操作可用 2 倍速快进，配音正常语速。

| 时间 | 操作 | 字幕/旁白 |
|------|------|-----------|
| 0:40-0:52 | 进入客户管理页，点击「导出」下载 Excel 文件，再点击「导入」选择文件上传成功 | 客户管理支持 Excel 批量导入导出，并提供模板下载 |
| 0:52-1:05 | 进入板材管理页，新增板材，上传纹理图片，列表展示纹理缩略图，点击缩略图打开大图预览（支持缩放、拖拽） | 板材支持纹理图片上传，列表展示缩略图，点击可大图预览 |
| 1:05-1:15 | 鼠标悬停大图，展示板材信息（品牌、材质、颜色、尺寸） | 大图预览支持缩放拖拽，悬停显示板材详细信息 |

---

## 场景 3：3D 柜体设计 → 产出订单明细（1:15-1:50，35s）

> 录制角色：operator。从订单录入页 `/cutting/data-input` 开始。

| 时间 | 操作 | 字幕/旁白 |
|------|------|-----------|
| 1:15-1:20 | 在订单录入页点击「3D 柜体设计」按钮，进入 3D 建模页 | 进入三维柜体设计页面 |
| 1:20-1:30 | 从预设模板逐一添加三个柜体到场景中 | 基于 Three.js 的三维建模，支持预设模板快速创建 |
| 1:30-1:38 | 点击「板材映射」，为柜体分配板材，展示纹理映射到 3D 模型 | 板材映射将纹理贴图同步到三维模型，所见即所得 |
| 1:38-1:45 | 点击「拆单预览」→ 确认写入订单，自动返回订单录入页 | 一键拆单将三维设计转化为订单明细，自动回填到订单 |
| 1:45-1:50 | 返回订单录入页，展示拆单生成的订单明细已自动填入 | 三维设计产出的板件数据已自动填入订单 |

---

## 场景 4：人工增补订单明细（1:50-2:10，20s）

> 录制角色：operator。从场景 3 返回的订单录入页衔接。

| 时间 | 操作 | 字幕/旁白 |
|------|------|-----------|
| 1:50-2:00 | 在已有拆单数据的订单录入页，手动添加几条增补明细，展示 TSV 批量粘贴 | 支持手动增补订单明细，TSV 批量粘贴提升录入效率 |
| 2:00-2:10 | 确认订单数据完整，点击底部「生成排版草稿」，跳转到排版工作台 | 订单数据就绪，生成排版草稿进入排版流程 |

---

## 场景 5：排版工作台 — 算法核心（2:10-3:05，55s）

> 录制角色：operator。从场景 4 跳转的排版工作台衔接。算法计算部分可用 2 倍速快进。

| 时间 | 操作 | 字幕/旁白 |
|------|------|-----------|
| 2:10-2:18 | 排版工作台页面全景 | 排版工作台是系统核心，集中管理排样任务和结果 |
| 2:18-2:28 | 点击「刀具参数」，展示排版参数（刀路宽度、安全边距、允许旋转）和加工参数（切割深度、切削进给、主轴转速），调整后确认 | 可调整刀具和排版参数，适配不同加工设备和工艺要求 |
| 2:28-2:34 | 点击「开始排版」，算法执行中（快进，叠加文字：计算耗时约 X 秒） | 执行排样算法，计算最优排列方案 |
| 2:34-2:46 | 计算完成，展示 Canvas 2D 排版结果；鼠标悬停某个板件，展示详情标签（零件名、尺寸、封边、微型地图） | 排版结果可视化呈现，悬停查看每个板件的详细信息 |
| 2:46-3:05 | 点击上方板材标签页切换不同板材，展示每块板材的利用率；顶部汇总栏展示总板件数、总利用率 | 多块板材逐一查看，每块独立计算利用率，整体材料使用情况一目了然 |

---

> 分两段录制：Web 端（operator）+ 小程序端（viewer）。

### Web 端（operator）

| 时间 | 操作 | 字幕/旁白 |
|------|------|-----------|
| 3:05-3:15 | 在排版完成的页面点击「分配生产」，选择生产员 | 排版完成后一键分配生产任务，指定执行人员 |
| 3:15-3:25 | 进入生产看板，展示三列看板（待生产/生产中/已完成） | 生产看板实时展示任务状态流转 |

### 小程序端（viewer）

| 时间 | 操作 | 字幕/旁白 |
|------|------|-----------|
| 3:25-3:32 | 微信小程序用 viewer 登录，展示「我的任务」列表 | 生产员通过小程序查看分配给自己的生产任务 |
| 3:32-3:40 | 点击任务详情，查看板材/部件信息，点击「开始生产」→「完成任务」 | 查看任务详情，执行生产状态流转 |
| 3:40-3:50 | 展示 NC 文件下载 | 支持下载 NC 切割文件，指导车间设备加工 |

## 录制前准备清单

- [ ] 启动后端服务：`./mvnw spring-boot:run`（端口 8080）
- [ ] 启动前端服务：`cd frontend && npm run dev`（端口 5173）
- [ ] 确保 MySQL 数据库有测试数据（客户、板材、订单明细）
- [ ] 准备 Excel 导入模板文件（客户模板，用于场景 2）
- [ ] 准备纹理图片文件（JPG/PNG，用于场景 2 板材上传）
- [ ] 预登录四个测试账号到不同浏览器/隐身窗口：admin、org_admin、operator、viewer
- [ ] 微信开发者工具启动小程序项目，viewer 账号已登录
- [ ] 录制软件配置好 1920×1080 分辨率，关闭通知弹窗
- [ ] 确认 3D 柜体设计页有可用的预设柜型模板
- [ ] 确认排版工作台有可执行的订单数据

## 录制注意事项

1. **鼠标移动要慢**：侧边栏扫过、悬停展示等操作，鼠标移动速度控制在 1-2 秒/项
2. **停留时间充足**：每个关键画面至少停留 2 秒，确保字幕可读
3. **快进标注**：快进段落在后期叠加「2x」标识和实际耗时文字
4. **分段衔接**：每段录制前后留 1 秒空白，方便剪辑
5. **字幕时机**：字幕与操作同步出现，每条字幕持续到该步骤结束

## 后期制作要点

1. 按场景顺序拼接 6 段录制素材
2. 为每条字幕添加文字（可参考脚本中的字幕/旁白列）
3. 场景 2 和场景 5 的快进段落添加 2 倍速和时间标注
4. 场景 1 的登录页叠加四角色说明文字
5. 片头可加系统名称 + 学校/姓名信息（可选）
6. 导出格式：MP4，1080p，30fps
