开发环境与工具
本系统为柜门板材切割排版系统，开发环境由后端服务、网页端和微信小程序端组成。后端采用 Java 17 作为主要开发语言，基于 Spring Boot 3.5.11 搭建业务服务。Spring Boot 是 Java Web 开发中常用的轻量级框架，具有自动配置、内嵌服务器和快速集成第三方组件等特点，能够减少传统 Spring 项目的配置工作。本系统利用 Spring Boot 提供 REST 接口，完成用户认证、客户管理、板材管理、订单管理、排样算法调用和排样结果管理等功能。
项目使用 Maven 进行依赖管理、编译、运行和测试，数据库选用 MySQL 8.0+。持久层采用 MyBatis-Plus 3.5.15，它是在 MyBatis 基础上封装的增强工具，支持通用 CRUD、条件构造器和分页查询，可减少重复 SQL 编写，提高数据访问层开发效率。系统认证采用 JWT 与 Spring MVC Interceptor 结合的方式。JWT 用于传递登录凭证，拦截器负责在请求进入控制器前校验 token，从而保证受保护接口的访问安全。
网页端采用 Vue 3 + Vite 技术栈。Vue 3 是渐进式 JavaScript 框架，适合构建交互式单页应用，其组合式 API 便于组织页面状态、事件和复用逻辑。Vite 是新一代前端构建工具，具有启动速度快、热更新及时和配置简洁等优点。前端使用 Pinia 管理登录和业务状态，Vue Router 实现页面跳转，Axios 统一封装后端请求，并通过 Vite 的 /api 代理连接本地 Spring Boot 服务，便于前后端联调。
界面层引入 Element Plus 组件库。Element Plus 基于 Vue 3，提供表格、表单、弹窗、按钮、分页等常用后台管理组件，有助于提升开发效率并保持页面风格统一。针对排样结果可视化，本系统结合 Canvas 2D 绘制板材矩形、工件色块和排版布局，并支持缩放、平移、悬停提示和板材切换等交互。
小程序端采用微信小程序原生框架，主要用于现场录入、客户与板材管理、算法输入和结果查看，开发和预览依赖微信开发者工具。项目还使用 Lombok 简化实体类和 DTO 代码，使用 EasyExcel 处理表格数据。测试方面主要使用 Spring Boot Test、JUnit 与 MockMvc 覆盖接口鉴权、业务逻辑和算法关键场景，前端通过 npm run build 检查构建结果。整体环境能够满足系统开发、联调、测试和毕业设计演示需要。
