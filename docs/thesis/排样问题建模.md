第X章  排样问题建模

X.1  问题描述

柜门板材切割是家具制造中的关键工序。工厂采购的标准板材（如2440mm×1220mm）作为原材料，需要按照订单要求切割出尺寸各异的柜门板件。如何在一块或多块标准板材上合理排布这些板件，使得板材利用率最高、边角料浪费最少，是排样优化的核心问题。

将上述实际场景抽象为计算问题：给定一个长度为L、宽度为W的矩形容器，以及n个待排样的矩形工件，第i个工件的长度为l_i、宽度为w_i。允许工件旋转90度（旋转后尺寸变为w_i×l_i），工件之间及工件与容器边界之间需保留最小间隙距离gap。要求确定每个工件在容器中的放置坐标和方向，使得容器内已放置工件的面积之和与容器面积之比（即空间利用率）最大。当单个容器无法容纳全部工件时，系统采用相同规格的多个容器依次排样，最终目标等效为用最少的容器装下全部工件。

该问题的本质是二维矩形装箱问题（2D Rectangular Bin Packing Problem），属于经典的NP-hard组合优化问题。随着矩形数量的增长，解的搜索空间呈指数级膨胀，无法通过穷举法在合理时间内求得精确最优解，因此必须采用启发式或元启发式算法在可接受的时间内逼近较优解。

X.2  数学模型

为清晰描述问题，首先定义符号体系：

容器参数：容器长度L，容器宽度W，容器面积S = L × W。
工件集合：n个矩形工件，第i个工件原始长度为l_i、原始宽度为w_i，面积为s_i = l_i × w_i。
全局参数：间隙距离gap（gap ≥ 0），旋转标志rotateEnable（布尔值）。

决策变量：
  放置坐标(x_i, y_i)：表示工件i左下角在容器内的位置，x_i为水平坐标，y_i为垂直坐标。坐标原点位于容器左下角。
  旋转指示r_i ∈ {0, 1}：r_i = 0表示工件保持原始方向，放置尺寸为(l_i, w_i)；r_i = 1表示工件旋转90度，放置尺寸为(w_i, l_i)。

约束条件如下。

（1）边界约束：每个工件必须完全放置在容器内部，且与容器边界保持间隙距离。

  r_i = 0时：gap ≤ x_i，x_i + l_i + gap ≤ L；gap ≤ y_i，y_i + w_i + gap ≤ W。
  r_i = 1时：gap ≤ x_i，x_i + w_i + gap ≤ L；gap ≤ y_i，y_i + l_i + gap ≤ W。

（2）不重叠约束：任意两个不同的工件i和j之间不允许重叠，并保持间隙距离。设工件i放置后的宽度为W_i、高度为H_i（W_i = r_i ? w_i : l_i，H_i = r_i ? l_i : w_i），则对于任意i ≠ j，以下四个条件至少满足其一：

  x_i + W_i + gap ≤ x_j  （工件i在工件j左侧）
  x_j + W_j + gap ≤ x_i  （工件i在工件j右侧）
  y_i + H_i + gap ≤ y_j  （工件i在工件j下方）
  y_j + H_j + gap ≤ y_i  （工件i在工件j上方）

（3）旋转约束：如果rotateEnable = false，则对所有i有r_i = 0。

目标函数（单容器）：最大化空间利用率rate：

  rate = (Σ_{i∈P} s_i) / S

其中P为成功放置到当前容器内的工件集合，S = L × W为容器面积。

当扩展到多容器场景时，设第k个容器中放置的工件集合为P_k，则目标是：在P_1 ∪ P_2 ∪ ... ∪ P_m = {1, 2, ..., n}且各P_k互不相交的条件下，最小化容器数量m。这是一种等效转化——利用率越高，相同数量的工件占用更少的容器，因此两个目标函数在本质上是统一的。

由于该问题属于NP-hard，当n较大时不存在多项式时间的精确算法。本文采用"排列编码+启发式解码+元启发式搜索"的两阶段求解框架：将问题分解为确定矩形放置顺序的组合优化主问题，以及按给定顺序通过天际线算法确定具体坐标的放置解码子问题。

X.3  求解框架

求解框架包含三个核心组件：编码方案、解码算法和搜索策略。

（1）编码方案。采用基于排列的编码方式，将一个解表示为一个矩形工件的排列序列π = (π_1, π_2, ..., π_n)，其中π_k表示第k个被放置的工件序号。排列顺序决定了工件放置的优先级：排在序列前面的工件优先选择放置位置，因此不同的排列会导致不同的放置结果和空间利用率。这种编码方式将原本连续的坐标决策变量转化为离散的排列组合问题，缩小了搜索空间的编码维度。

（2）解码算法。给定一个排列π，解码器负责将其翻译为具体的放置方案（各工件坐标和方向）。本文采用天际线放置算法作为解码器：它维护容器内已放置区域顶部轮廓的一组水平线段（天际线），按排列顺序逐个取工件，在天际线中寻找最低的、可容纳该工件的水平位置进行放置，放置后更新天际线轮廓。该算法保证每个工件被放置在当前轮廓的最低可行位置，有利于减少碎片化空隙。解码完成后，计算利用率作为该排列的适应度评分。

（3）搜索策略。采用禁忌搜索在排列空间中寻优。禁忌搜索从一个随机初始排列出发，每轮迭代生成多个邻域排列（通过随机交换排列中的若干对矩形位置产生），分别解码评分，选择其中的最优邻域解作为下一轮迭代的起点。禁忌表记录已访问过的排列路径，防止搜索陷入循环和局部最优。算法在预设的迭代代数内持续寻优，最终返回历史最优排列及其解码方案。

（4）多容器迭代。当单个容器完成排版后仍有剩余工件未放置，系统将已放置工件从列表中移除，用相同规格的新容器对剩余工件重复上述求解过程，直至所有工件排完或判定存在无法装入容器的工件。

X.4  天际线放置算法

天际线（Skyline）是一种表示二维容器内可用空间顶部轮廓的数据结构。在任意时刻，天际线由一组水平线段组成，每条线段包含三个属性：起点x坐标、当前高度y、线段宽度width。所有线段在x轴方向上首尾相接，共同勾画出容器内的已占用区域边界。

算法流程如下。

初始化：天际线初始化为一条线段，起点x = gap，高度y = gap，宽度width = L - 2×gap。这表示容器底部从gap到L-gap的水平区域均为可用空间，初始高度为gap。

逐个放置：对于排列π中的每个工件i，获取其原始长度l_i和宽度w_i。根据旋转开关和边界约束条件，生成候选放置尺寸列表：如果允许旋转则包含(l_i, w_i)和(w_i, l_i)两个选项，否则仅包含(l_i, w_i)。对每种候选尺寸，设放置所需宽度为w、高度为h，遍历天际线所有线段，寻找满足以下条件的位置：线段宽度≥w，放置后x + w + gap ≤ L，且y + h + gap ≤ W（不超出容器边界）。若单条线段宽度不足，检查相邻且高度相同的多条线段合并后能否提供足够宽度。在所有可行位置中，优先选择高度最低的位置；高度相同时优先选择x坐标最小（最靠左）的位置。这体现了"最低最左"的贪心策略。

旋转处理：对每种候选尺寸独立评估，选择产生最优放置的尺寸。在代码实现中，两种候选尺寸参与同一轮扫描，按最低最左原则统一比较，旋转选项自然胜出当且仅当它能带来更低或更左的放置位置。

天际线更新：工件成功放置后，需更新天际线以反映新占用的空间。将天际线中被该工件x方向覆盖的线段进行分割：工件左侧未覆盖部分保持原高度不变，工件右侧未覆盖部分同样保留，工件正上方区域新增一条线段，其x坐标为工件放置x坐标，宽度为工件实际放置宽度，高度为原放置位置y + h + gap。更新后对天际线线段按x坐标排序，合并相邻且高度相同的连续线段，以减少线段数量并保证天际线始终简洁。

算法复杂度：对每个工件，需遍历全部天际线线段寻找最优位置，时间复杂度为O(m × n)，其中m为天际线线段数量（通常远小于n），n为工件数量。线段合并在每次放置后执行，复杂度为O(m log m)。

X.5  禁忌搜索

禁忌搜索是一种元启发式算法，通过在解空间中迭代移动并利用禁忌表记忆近期访问过的解，避免搜索陷入局部最优和循环。本系统中禁忌搜索用于优化矩形排列顺序。

初始解：对矩形工件列表执行一次随机打乱，将打乱后的排列作为初始解。对该排列调用天际线解码器计算利用率，作为初始的全局最优解和局部最优解。

邻域结构：从当前排列出发，随机选取6对位置进行交换，生成一个新的邻域排列。每次交换随机选择两个不同的索引，交换这两个位置上的工件。连续执行6次交换后得到的新排列即为一个邻域候选解。该邻域算子的设计意图是在当前解附近进行中等强度的扰动——交换次数过少则搜索步长太小、易陷入局部最优；交换次数过多则退化为随机跳跃、丧失局部搜索能力。

禁忌表：采用树形结构存储已访问的排列。树的根节点为排列中第一个工件，子节点按排列顺序依次展开，形成一条从根到叶的路径。禁忌表外层使用哈希映射，键为首个工件的ID，值为对应的树结构，以此将搜索过的排列按首工件分组管理。当生成一个新排列时，先检查其是否已存在于禁忌树中：若存在则跳过评价，避免重复搜索；若不存在则加入禁忌表并进入解码评价环节。

搜索主循环参数：最大迭代代数MAX_GEN = 300，每代生成邻域候选解数量N = 500。算法主流程如下。

  Step 1: 初始化随机排列、全局最优解bestSolution和局部最优解LocalSolution。
  Step 2: 对于每一代t = 1, 2, ..., 300：
    Step 2.1: 生成本代最优解LocalSolution（初始为空）。
    Step 2.2: 重复N = 500次：
      对当前排列执行6次随机交换生成新排列；
      若该排列不在禁忌表中，加入禁忌表并调用天际线解码器评分；
      若评分优于本代最优，更新LocalSolution。
    Step 2.3: 若本代最优评分优于全局最优，更新bestSolution。
    Step 2.4: 将本代最优排列作为下一代的起点。
  Step 3: 返回全局最优解bestSolution。

特赦准则：当某一邻域解的利用率高于当前全局最优解时，即使该排列已存在于禁忌表中也予以接受。这一准则确保算法不会因为禁忌表的限制而错失潜在的全局更优解。

终止条件：达到预设的最大迭代代数300后，返回历史最优解。

X.6  多容器策略

当工件数量较多或容器尺寸有限时，单个容器往往无法容纳全部工件。本系统采用迭代贪心填充策略处理多容器场景。

策略流程如下：

  Step 1: 维护一个剩余工件列表，初始包含全部待排样工件。
  Step 2: 以剩余工件列表为输入，构造单个容器的排样实例，调用禁忌搜索求解当前容器。
  Step 3: 从求解结果中提取成功放置的工件，通过尺寸匹配（考虑旋转）从剩余工件列表中逐一移除。
  Step 4: 若本轮有工件被移除，且剩余工件列表非空，则回到Step 2开始下一个容器。
  Step 5: 若本轮没有工件被移除（主搜索未能装入任何工件），触发单件兜底机制：逐一尝试将每个剩余工件单独放入容器，选择利用率最高的单件方案作为本轮结果。若单件兜底仍无任何工件可放入，则判定存在工件尺寸超出容器容纳能力，终止求解并报告错误。

该策略的核心思想是：每次求解聚焦于当前容器的最优排布，将已排工件移除后问题规模逐步缩小。每个容器独立求解，但同一规格的容器尺寸保持不变，最终输出一组容器的排样方案列表，每个方案包含该容器的利用率和工件坐标信息。

单件兜底机制的必要性在于：禁忌搜索依赖邻域交换和迭代改进，当剩余工件数量较少时，搜索可能因缺乏有效的邻域移动而停滞。逐个评估单件放置可以保证——只要存在至少一个工件的尺寸允许其放入容器——算法就能继续推进，不会因搜索停滞而导致全局求解中断。
