Abstract
For cabinet door panel processing, there are problems such as scattered cutting data, low manual layout efficiency, unstable utilization, and difficult tracing. So this paper designs and implements a cutting and nesting system based on Spring Boot, achieving a complete process from data maintenance, data entry, intelligent nesting, 3D design, visualization to task management. The system uses Spring Boot, MyBatis-Plus, MySQL for backend, JWT for authentication, and tenant interceptor for data isolation. Web frontend uses Vue 3, Element Plus, Canvas 2D for management and visualization, integrates Three.js for 3D design. Mini-program uses WeChat native framework for on-site entry and viewing. Main functions include RBAC, organization, customer, material, order, scrap, nesting result, 3D cabinet design, production task, dashboard and algorithm solving.
In permission management, the system designs four roles and 14 permission codes, implements fine-grained access control through route guards and button directives. In production management, the system implements complete task lifecycle, supporting batch allocation, three-state transitions and kanban drag-drop. In 3D design, the system builds interactive workbench based on Three.js, supporting template management, drag-drop alignment, rendering and splitting preview.
This paper combines production management with intelligent nesting, constructs implementable solution for actual processing scenarios. The paper designs a combined strategy based on "tabu search + skyline algorithm", and implements genetic algorithm as alternative. Tabu search takes arrangement order as search object, generates neighborhood through swaps, uses tabu table to reduce local optima risk. In evaluation, skyline algorithm completes placement: maintains segments based on contour, checks constraints, prioritizes lower-left points to improve utilization. Additionally, the algorithm supports multi-container solving, rotation control, spacing constraints, utilization calculation and coordinate output, so results meet constraints and can be used for visualization and persistence.
In testing, this paper uses ApiFox for core interfaces and Chrome for frontend verification. Results show the system can complete login, permission control, data maintenance, parameter validation and algorithm solving. Interfaces have clear structure, frontend can display tables, draw nesting diagrams and render 3D cabinets. Overall, the system runs stably with broad coverage, basically meeting actual business needs.
Keywords: panel cutting; multi-container nesting; tabu search; role-based access control; Spring Boot; Vue 3; Three.js
