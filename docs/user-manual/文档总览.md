# 文档总览

整理日期：2026-05-09

本文档是项目文档索引，说明每份文档的用途和适用场景。

## 1. 项目定位

柜门板材切割排版系统 — 切割优化引擎 + 生产管理平台。核心能力：禁忌搜索/遗传算法双策略排样、订单生命周期状态机、RBAC 权限、操作审计、Docker 部署、Excel 导入导出。

## 3. 推荐阅读顺序

| 顺序 | 文档 | 场景 |
|------|------|------|
| 1 | `AGENTS.md` | 了解项目全貌 |
| 2 | `docs/user-manual/操作手册.md` | 部署和日常使用 |
| 3 | `docs/planning/expansion-plan.md` | 了解当前进度和后续规划 |
| 4 | `docs/planning/known-issues.md` | 避免已知陷阱 |
| 5 | 算法文档 | 对接或修改排样算法 |

## 4. 维护规则

1. 项目级事实（接口、模型、约定）统一更新 `AGENTS.md`。
2. 部署、配置、使用说明更新 `docs/user-manual/操作手册.md`。
3. 功能规划变更更新 `docs/planning/expansion-plan.md`。
4. 通用开发陷阱追加到 `docs/planning/known-issues.md`。
5. 数据库结构变更追加 migration SQL 并更新迁移记录。
6. 算法实现变更同步更新算法模块两份文档。
7. 不再把临时 HTML、测试页面放到 `src/main/java` 或 `src/main/resources` 业务目录中。
